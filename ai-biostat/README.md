# AI-Biostat — сайт для пилота (этап 1)

Что уже работает:
- вход по коду участника и паролю из 6 цифр (без ФИО);
- автосохранение каждого шага: студент закрыл вкладку — вернулся на то же место;
- входная диагностика сохраняется на сервере;
- кейс 21 полностью (10 шагов), оспаривание оценки;
- учёт для исследования: переходы к ИИ-репетитору, запуски кода, переходы между шагами;
- панель преподавателя: оспаривания с обязательным обоснованием, подтверждение оценок, список участников;
- выгрузка CSV для Excel (только коды участников);
- журнал действий (входы, выгрузки, решения).

Ещё не сделано (следующие этапы): настоящий запуск R/Python в браузере, кейсы 1, 4, 22, 23,

## 1. Запуск на своём компьютере (проверка)

1. Установите Python 3.11 или новее: https://www.python.org/downloads/ (при установке отметьте «Add Python to PATH»).
2. Распакуйте архив, откройте терминал (Windows: «Командная строка») в папке `ai-biostat`.
3. Установите зависимости:
       pip install -r requirements.txt
4. Создайте участников (пример — файл `участники_пример.csv`):
       python tools/participants.py import участники_пример.csv
   Появится файл `пароли_<дата>.csv` с кодами и паролями.
5. Запустите сайт:
       python -m uvicorn app.main:app --port 8000
6. Откройте в браузере http://localhost:8000 и войдите кодом и паролем из файла паролей.
   Код T-0001 — преподаватель.

## 2. Участники

Файл CSV, столбцы `code;role;group;lang`:
- `role`: `student` (студент), `specialist` (специалист), `teacher` (преподаватель/автор);
- `lang`: `kk`, `ru` или `en` — язык интерфейса по умолчанию.

ФИО в систему не вносятся. Таблицу «код — ФИО» автор хранит отдельно.
Файл паролей раздайте участникам и удалите.

- Новый пароль одному участнику: `python tools/participants.py reset P-0001`
- Список участников: `python tools/participants.py list`

## 3. Данные и резервная копия

Все данные — в одном файле `data/ai_biostat.db`. Резервная копия — скопировать этот файл
(лучше ежедневно, при остановленном сайте или в тихое время).

## 4. Размещение для пилота

Нужен сервер вуза или VPS (Linux, 1 ГБ памяти достаточно для ~300 участников) и адрес сайта с HTTPS.
Вариант с Docker:
       docker build -t ai-biostat .
       docker run -d -p 8000:8000 -v $(pwd)/data:/app/data -e AIB_SECURE_COOKIE=1 ai-biostat
Перед сайтом ставится nginx или Caddy с HTTPS-сертификатом (это настроит ИТ-отдел вуза).
`AIB_SECURE_COOKIE=1` включать только при работе через HTTPS.

## 4а. Amazon (AWS) одной командой

На сервере Ubuntu (EC2) в окне «EC2 Instance Connect»:

       git clone https://github.com/ВАШ_ЛОГИН/ai-biostat.git && cd ai-biostat && sudo bash deploy/setup.sh

Скрипт ставит всё сам, включает HTTPS (адрес вида https://3-121-45-6.sslip.io) и ежедневную резервную копию.
Участники на сервере:  `sudo aib-participants import участники.csv`
Обновить сайт после изменений:  `cd ~/ai-biostat && git pull && sudo bash deploy/setup.sh`
